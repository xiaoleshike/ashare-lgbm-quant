# Daily Model Explainability

The explainability layer is a read-only research step over an already published champion-model
prediction and candidate list. It does not alter scores, ranks, features, or candidate filters and
does not produce trading instructions.

Run it after production prediction and candidate selection:

```bash
ashare-quant --config config/default.yaml research explain --as-of 20260717
```

The command writes `reports/YYYYMMDD/explanations.json` and `explanations.md`. It verifies report
dates, champion identity, the ordered feature hash, recomputed scores, and TreeSHAP additivity. It
loads only the champion's feature columns from `features_daily`; labels and future data are never
read.

SHAP `TreeExplainer` is preferred when the optional `shap` package is available. Otherwise,
LightGBM's native `pred_contrib=True` TreeSHAP implementation is used. In either case the base value
plus all feature contributions must reconstruct the immutable prediction score within the configured
tolerance.

Same-day score percentiles compare stocks within the complete daily prediction universe. Historical
percentiles use only earlier prediction files generated by the identical `model_id`. Different model
versions are never mixed. Until sufficient same-model sessions exist, historical confidence is
reported as limited or unavailable. Confidence describes historical sample coverage, not expected
return certainty.

Contribution signs show whether a feature raised or lowered the model's raw ranking score relative
to its baseline. They are model explanations, not causal claims or investment recommendations.
